### `05cd503` — ui(mobile): iOS/Android optimization

Сделали полный mobile-pass по CSS — все ключевые страницы (landing, login, catalog, agent page, dashboard, seller).

**Globals (`src/app/globals.css`):**
- `-webkit-text-size-adjust: 100%` + `overflow-x: clip` — никаких побочных горизонтальных скроллов от анимаций / видео
- `-webkit-tap-highlight-color: transparent` — наши hover/active стили чище
- `input/select/textarea ≥ 16px` на мобилке (`@media max-width 640`) — iOS не зумит при фокусе
- `min-h-screen` → `100dvh` где `@supports (height: 100dvh)` — учитывает скрытие адресной строки

**Layout:**
- `viewport.viewportFit: "cover"` — `env(safe-area-inset-*)` начинает работать

**Header + drawer:**
- `padding-top: env(safe-area-inset-top)` на sticky header — notch не лезет в контент
- Burger 40→44 px (Apple HIG)
- Drawer: `padding-bottom: env(safe-area-inset-bottom)` + пункты py-2→py-3 (15px)

**Login:**
- top/bottom strips: safe-area для {top, bottom, left, right}
- SSO кнопки: `min-height 44px` + active-state для тача
- ≤320px (Galaxy Fold front cover): SSO в столбец

**Catalog:**
- search/select h-9→h-11 на мобилке (44px touch target)
- sticky filter bar учитывает notch (`top: calc(3.5rem + env(safe-area-inset-top))`)

**Agent page:**
- back-кнопка ← в top strip: 32×32 минимум tap-zone

### `ea89b12` — ui(mobile): dvh fallback for dashboard cockpit + seller hero

`@supports (height: 100dvh)` поверх существующих `min-height: 100vh` в `cockpit.css` (`/dashboard`) и `BecomeSellerLanding.module.css` hero (`/seller`) — убирает «прыжок» высоты на iOS при коллапсе URL-бара.

## 2. Что НЕ проверено (нужен реальный телефон)

Делали статический CSS-аудит, без живого рендера в DevTools/Safari/Chrome iOS. Юзер выбрал статику вместо установки playwright. Поэтому следующее **не верифицировано** и может требовать точечных правок:

| Зона | Что может всплыть |
|---|---|
| `/` HeroCockpit | На <360px (iPhone SE) метрики 4-в-1 могут жать — media-rules для 640/900 есть, но реальная посадка не видна |
| `/` FlowHorizontal/Cinematic | Длинные секции, тач-скролл, паузы анимации, BackgroundVideo на slow 3G |
| Agent page aside | Sticky на десктопе, static на mobile — выглядит как блок в конце страницы под скроллом, проверить порядок |
| Telegram widget login | На мобиле iOS Safari может блокировать `window.Telegram.Login.auth` — fallback URL прописан в `LoginSocialRow.tsx` |
| Dashboard cockpit | Терминал-стиль логи могут уехать вправо если очень длинные строки |
| PreLaunchBanner X | 24×24, маленькая тап-зона. Не критично т.к. corner-dismiss |

**Решение если вылез регресс:** откатить mobile-pass точечно через `git revert 05cd503` (он отдельный коммит от дизайна).
