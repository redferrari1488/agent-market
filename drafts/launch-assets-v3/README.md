# launch-assets-v3 · исходники картинок (Claude Design)

Это JSX-исходники для launch-картинок v3, скачаны из дизайн-канваса
(api.anthropic.com/v1/design). Локально работают через `v3.html`.

## Что внутри

- `v3.html` — entry, открывай в браузере (двойной клик)
- `design-canvas.jsx` — обёртка-канвас с артбордами
- `v3-app.jsx` — список всех артбордов
- `v3-smb.jsx` — посты под малый бизнес (РУ)
  - `V3PostNoDevs` — «без разработчиков» (картинка #2)
  - `V3PostSMBPains` — «типичная неделя» (картинка #6)
  - `V3PostChatStory` — «ответил клиенту пока спали» (картинка #7)
  - `V3PostNoDevWide` — широкая версия 1600×900
- `v3-stats.jsx` — посты про рост рынка $5.4B → $47B
  (НЕ ИСПОЛЬЗОВАТЬ — целевая не покупает по CAGR, см. drafts/launch-post-image-matrix.txt)
- `v3-lockin.jsx` — коллаб-материалы hire.on × LOCK·IN
- `tokens.css`, `nav-pill.css`, `nav-pill.js` — общее оформление

## Как пересобрать PNG

1. Открой `v3.html` в браузере (Chrome/Safari)
2. Дождись пока React загрузит артборды
3. Найди нужный артборд (например «4 рутины СМБ» = #6)
4. Меню «⋯» в углу артборда → экспорт в PNG / HTML
5. Сохрани PNG куда нужно

После пересборки #6 и #7 станут безопасны для публикации.
