# Сценарии коротких видео (VK Клипы / YouTube Shorts / Rutube / Дзен-ролики)

Формат: вертикаль 9:16, 15-30 сек. Снять можно с экрана телефона/ПК + текст
поверх + простой голос или подпись. Без дорогого продакшна - честный screen-record
работает лучше глянца. Площадки только легальные РФ (НЕ Reels/Instagram).

Маркировка: органический контент в своих аккаунтах - НЕ реклама, erid не нужен.
Платное продвижение ролика - уже реклама, нужна маркировка.

Каждый ролик: ХУК в первые 2 секунды, иначе пролистнут.

---

## Ролик 1. «AI ответил на отзыв за 3 секунды»

- [0-2с] ХУК. Текст на экране: «у бизнеса 40 отзывов без ответа». Кадр - реальная
  карточка 2ГИС с неотвеченными отзывами.
- [2-8с] Показываем: вставляем отзыв → агент пишет ответ в тоне бренда. Реальный
  экран, реальный ответ появляется.
- [8-15с] «и так на каждый новый отзыв, сам, 24/7». Быстрая прокрутка нескольких
  ответов.
- [15с] Подпись: «2000₽/мес, неделя бесплатно. hireon.agency».

## Ролик 2. «Бот закрыл клиента, пока ты спал»

- [0-2с] ХУК. «3 часа ночи. клиент пишет в telegram».
- [2-10с] Скрин переписки: клиент задаёт вопрос → бот мгновенно отвечает по FAQ →
  клиент оформляет. Время на экране - 03:14.
- [10-15с] «без бота этот клиент ушёл бы к тому, кто ответил. бот не спит».
- [15с] «бот поддержки, 2990₽/мес. hireon.agency».

## Ролик 3. «Этот канал ведёт AI» (dogfooding, честно)

- [0-2с] ХУК. «честно: половину постов тут пишет не человек».
- [2-12с] Показываем агента-копирайтера: задаём тему → выходит пост в тоне канала.
  «он держит канал живым по расписанию, я только правлю».
- [12-15с] «если ты не отличил - значит, работает».
- [15с] «копирайтер канала, 990₽/мес».

## Ролик 4. «До и после» (рейтинг 2ГИС)

- [0-2с] ХУК. Большая цифра «4.3» и стрелка вниз.
- [2-10с] «отзывы шли, но никто не отвечал - рейтинг полз вниз». Показываем
  неотвеченные отзывы.
- [10-15с] Подключили агента → отвечено на всё → «4.3 → 4.6 за [N] недель».
- [15с] CTA. (Снять, когда будет первый реальный кейс с цифрами.)

## Ролик 5. «Сколько стоит менеджер vs агент»

- [0-3с] ХУК. Две колонки: «менеджер на поддержке - 60-100к/мес» / «бот - 2990».
- [3-12с] «бот не болеет, не увольняется, не спит, отвечает за секунду. он не
  заменит человека везде - но рутину закроет».
- [12-15с] «начни с рутины. hireon.agency».

## Ролик 6. «Малый бизнес не покупает AI» (позиционирование)

- [0-3с] ХУК. «в наших карточках почти нет слова нейросеть. и это специально».
- [3-12с] «владельцу кафе не нужен AI. ему нужно - отвечено на отзывы, закрыты
  вопросы, канал не пустой. технология - наша забота».
- [12-15с] «готовые агенты под задачи бизнеса. hireon.agency».

---

## Общие правила

- Снимать сериями по 2-3 за один присест - так дешевле по времени.
- Один ролик = одна мысль. Не пихать весь каталог.
- Реальный экран > стоковая графика. Люди верят «живому» скрину.
- Звук: можно без голоса, текстом на экране (многие смотрят без звука), но
  субтитры/подписи обязательны.
- В описании - ссылка hireon.agency и 1-2 хэштега ниши.
