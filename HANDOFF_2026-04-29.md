## 3. Pivot на Gemini-модель (главное стратегическое решение сессии)

**Раньше планировалось:** свои агенты + waitlist для сторонних + подписки Pro 990 / Featured 2990 ₽/мес для продавцов.

**Сейчас:** свои агенты + бесплатное размещение для сторонних + boost-монетизация (рекламные услуги, разово) + биржа заказов + консалтинг.

### Почему сменили курс

1. Подписочные тарифы для продавцов — серая зона при ФНС-проверке (могут признать скрытым посредничеством).
2. Подписка от продавца на пустой каталог никто не купит → деньги в Phase 0 идут только со своих агентов в любой модели.
3. Бесплатное размещение → ниже барьер входа → быстрее наполнение каталога.
4. UX «Запросить доступ» через waitlist хуже, чем прямая outbound-ссылка на ресурс продавца.
5. Boost = разовая оплата за рекламу — чёрно-белая легальность под НПД.

### Что упустил Gemini, что добавили

- Свои агенты founder'a через ЮКассу — основной поток выручки в первые месяцы. Оставлено.
- Триггеры перехода на ИП — без изменений (5+ продавцов + 20+ заявок ИЛИ >150к/мес выручки).

Подробное обоснование — в auto-memory `project_pre_launch_strategy.md` (обновлено в этой сессии).

## 5. UX-проблема, которую я обнаружил, но не починил

**В шапке (`src/components/layout/Header.tsx:64-69`) две ссылки в выпадашке:**
- «Стать продавцом» → `/seller`
- «Создать агента» → `/seller/agents/new`

**Обе показываются всем пользователям независимо от роли.** Для нового юзера обе ведут к одному и тому же месту:
- «Стать продавцом» → `/seller` → форма заявки
- «Создать агента» → `/seller/agents/new` → role check fail → redirect на `/seller` → та же форма заявки

То есть **silent redirect для непродавца**: он жмёт «Создать агента», ожидает форму создания, попадает на форму заявки, не понимая что произошло.

### Как фиксить (3 строчки в Header.tsx)

Сделать `extraNav` динамическим в зависимости от `user.role`:

```ts
// Header.tsx:64-69 → заменить на функцию
function getExtraNav(role: string | null) {
  const sellerLinks = (role === "seller" || role === "admin")
    ? [
        { name: "Панель продавца", href: "/seller" },
        { name: "Создать агента", href: "/seller/agents/new" },
      ]
    : [{ name: "Стать продавцом", href: "/seller" }];

  return [
    { group: "Платформа", links: [{ name: "Каталог", href: "/agents" }] },
    { group: "Продавцам", links: sellerLinks },
    { group: "Компания", links: [
      { name: "О проекте", href: "/about" },
      { name: "Контакты", href: "/contacts" },
    ]},
  ];
}
```

И в `Header()` заменить `extraNav` на `getExtraNav(user?.role ?? null)`. Build green, ~5 минут работы.

**Не блокер для ЮКассы** — это про UX непродавцов в шапке. Можно делать в следующей сессии. Не забыть.
