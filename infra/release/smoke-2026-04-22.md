## Why the smoke is blocked

This production build no longer allows the old checkout dev-stub in `NODE_ENV=production`.
That is correct behavior.

But the same VPS also has no configured payment providers:

- `/api/payments/providers` returns `[]`
- `/api/checkout` returns `503`
- no subscription row is inserted
- no `agent-<subscriptionId>` container can be created

So the requested payment path:

`register -> login -> /agents -> buy subscription -> pay via YooKassa -> agent container -> logs -> restart -> stop -> cancel`

is currently blocked at the payment-provider boundary.

## Release implication

This is still a real public-release blocker.

The next required step is not more browser work. It is to configure a real payment
provider on the VPS first, then rerun this smoke from the beginning.
